# Children's Screen Time Analysis

## Overview
An academic Data Mining project investigating relationships between children's screen time and demographic, health, lifestyle, and environmental factors.

**Course:** ITCS444 Data Mining, Mahidol University

**Status:** Phase 1 Completed — Exploration & Design

## Dataset
- Source: 2024 National Survey of Children's Health (NSCH)
- Records: 51,375
- Original Variables: 457

## My Contributions
- Conducted Exploratory Data Analysis (EDA).
- Created visualizations to explore screen-time patterns across age, learning curiosity, and household food security.
- Reviewed teammates' preprocessing code to understand missing-value handling and data preparation.

## Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Findings
Exploratory analysis identified differences in screen-time patterns across several demographic and behavioral factors.

These findings represent associations, not causal relationships.

## Future Work
Explore clustering techniques to identify groups of children with similar characteristics.

## Data Availability
The original dataset is not included in this repository. It can be obtained from the official National Survey of Children's Health public-use data source.
